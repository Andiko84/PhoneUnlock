# PhoneUnlock

PhoneUnlock turns your Android phone into a wireless security key for your Windows PC.

## Downloads

**Latest release: v1.0.1**

- [Windows — PhoneUnlockSetup.exe](./releases/PhoneUnlockSetup.exe)
- [Android — PhoneUnlock.apk](./releases/PhoneUnlock.apk)
- [SHA-256 checksums](./releases/SHA256SUMS.txt)

## Features

- Use your Android phone as a wireless security key for Windows
- Bluetooth-based phone connection
- Automatic PC locking when your phone is no longer connected
- English, Italian and Albanian language support
- Windows and Android versions
- Built-in update checking

## How it works

PhoneUnlock pairs your Android phone with your Windows PC.

When your phone is connected, PhoneUnlock can keep the PC unlocked. When the phone is no longer connected, the PC can be locked automatically.

## Installation

### Windows

1. Download PhoneUnlockSetup.exe.
2. Run the installer.
3. Follow the installation instructions.
4. Open PhoneUnlock and pair your Android phone.

### Android

1. Download PhoneUnlock.apk.
2. Install the APK on your Android device.
3. Open PhoneUnlock.
4. Follow the pairing instructions shown by the Windows application.

> Android may require permission to install applications from unknown sources.
