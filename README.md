# PhoneUnlock

PhoneUnlock turns your Android phone into a wireless security key for your Windows PC.

## Downloads

### Windows

[Download PhoneUnlock for Windows](./releases/PhoneUnlockSetup.exe)

### Android

[Download PhoneUnlock for Android](./releases/PhoneUnlock.apk)

## Version

**1.0.1**

## Features

- Android phone as a wireless Windows security key
- Bluetooth-based connection
- Automatic PC locking when the phone is no longer connected
- English, Italian and Albanian language support
- Windows and Android versions

## Installation

### Windows

1. Download PhoneUnlockSetup.exe.
2. Run the installer.
3. Follow the installation instructions.

### Android

1. Download PhoneUnlock.apk.
2. Install the APK on your Android device.
3. Open PhoneUnlock and follow the pairing instructions.

> Android may require permission to install applications from unknown sources.
